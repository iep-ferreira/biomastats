3 Data sources and connections

The package keeps no copies of its own. Each function goes to the original source, reads only the part it needs and caches whatever can be reused later.

layer_catalog() returns this same list for the external layers and, with online = TRUE, checks whether each server is responding.

Connections, failures and cache

For selective downloads, the package queries the Bioma Stats API (api.biomastats.org, with a backup mirror) to find out which files make up each tile. That list is cached for 7 days, and maps that were already downloaded are reused in later runs.

External layers have a 5-second time limit. If a source does not respond in time, fails or refuses access, it is set aside: the function returns that block with status "skipped" and carries on with the others, without stopping the analysis. On slow connections, the limit can be raised with options(biomastats.timeout = 10).

Extracts, indexes and file lists are kept in the user cache (tools::R_user_dir("biomastats", "cache")). Interrupted downloads leave no partial files behind.

Institutions with their own mirrors can point the package to them, for example with options(biomastats.worldcover_root = "https://..."). The options biomastats.copernicus_root, biomastats.soilgrids_wcs and biomastats.overture_stac are also available.
