12 Connectivity over time

connectivity_change() repeats the analysis over several years and compares the loss of habitat (dA) with the loss of connected area (dECA), like Makurhini’s MK_dECA(). When dECA falls more than dA, connectivity is being lost faster than habitat:

polygon_series <- reclass_to_polygons(metrics, years = c(1985, 2004, 2024), save_shp = FALSE)
change <- connectivity_change(polygon_series, max_dist = 300, metric_patch = c("IIC", "PC"),
  p_ref = 0.05, d_ref = 300, language = "en")
change$change_plot
Year Habitat (ha) ECA (ha) dA (%) dECA (%) rECA Change
1985 199.89 129.70 NA NA NA Baseline
2004 114.85 57.41 -42.54 -55.74 1.31 Connectivity loss > habitat loss
2024 106.80 49.71 -7.01 -13.41 1.91 Connectivity loss > habitat loss

fractions_plot shows how intra, direct links and stepping stones change over the years, and map_plot the importance of fragments in each year. With animate = TRUE and the gganimate package, animation shows the same map year by year:

change <- connectivity_change(polygon_series, max_dist = 300, metric_patch = "PC",
  link_importance = TRUE, animate = TRUE, language = "en")
gganimate::animate(change$animation, fps = 1)

Integration with Makurhini

as_makurhini() prepares the arguments of MK_dPCIIC(), MK_dECA() and MK_ProtConn() with the same fragments, areas, boundary, distances and k calibration, and with run = TRUE runs Makurhini when it is installed:

mk <- as_makurhini(connectivity_pc, "dPCIIC", run = TRUE)
protconn <- as_makurhini(connectivity_pc, "ProtConn", protected = protected_areas,
                         run = TRUE)
deca <- as_makurhini(change, "dECA", run = TRUE)
