Capítulo 12 Conectividade ao longo do tempo

connectivity_change() repete a análise em vários anos e compara a perda de habitat (dA) com a perda de área conectada (dECA), como o MK_dECA() do Makurhini. Quando dECA cai mais que dA, a conectividade se perde mais depressa que o habitat:

poligonos_serie <- reclass_to_polygons(metricas, years = c(1985, 2004, 2024), save_shp = FALSE)
mudanca <- connectivity_change(poligonos_serie, max_dist = 300, metric_patch = c("IIC", "PC"),
  p_ref = 0.05, d_ref = 300)
mudanca$change_plot
Ano Habitat (ha) ECA (ha) dA (%) dECA (%) rECA Mudança
1985 199,89 129,70 NA NA NA Linha de base
2004 114,85 57,41 -42,54 -55,74 1,31 Perda de conectividade > de habitat
2024 106,80 49,71 -7,01 -13,41 1,91 Perda de conectividade > de habitat

fractions_plot mostra como intra, ligações diretas e trampolins mudam ao longo dos anos, e map_plot, a importância dos fragmentos em cada ano. Com animate = TRUE e o pacote gganimate, animation mostra o mesmo mapa ano a ano:

mudanca <- connectivity_change(poligonos_serie, max_dist = 300, metric_patch = "PC",
  link_importance = TRUE, animate = TRUE)
gganimate::animate(mudanca$animation, fps = 1)

Integração com o Makurhini

as_makurhini() prepara os argumentos de MK_dPCIIC(), MK_dECA() e MK_ProtConn() com os mesmos fragmentos, áreas, limite, distâncias e calibração de k, e com run = TRUE executa o Makurhini, quando instalado:

mk <- as_makurhini(conectividade_pc, "dPCIIC", run = TRUE)
protconn <- as_makurhini(conectividade_pc, "ProtConn", protected = unidades_conservacao,
                         run = TRUE)
deca <- as_makurhini(mudanca, "dECA", run = TRUE)
