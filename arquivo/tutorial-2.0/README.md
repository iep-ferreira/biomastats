# Tutorial 2.0 (arquivado)

Tutorial em página única, bilíngue (pt/en), usado até a versão 2.0.0 do pacote.
Foi substituído pelo livro em `tutorial/` (bookdown), publicado em
<https://iep-ferreira.github.io/biomastats/>.

| Arquivo | Conteúdo |
|:--|:--|
| `tutorial.Rmd` | fonte R Markdown |
| `tutorial.html` | última renderização local |
| `index-publicado.html` | versão que estava publicada no GitHub Pages |
| `tutorial-biomastats.R` | código do tutorial em script |
| `tutorial_includes/` | tema, cabeçalho bilíngue, capa e logos |

Guardado apenas como referência; não é mantido nem compilado. O caminho da
coleção local e algumas funções (por exemplo, `zone`/`hemisphere` em
`biomastats_metrics()`) refletem a versão anterior do pacote.
